B.  DOMAIN QUALIFICATION for D = d/du
==============================================================================
  [A,D] = -I was verified on polynomials (checks.py section 5).  Polynomials
  restricted to (-L,L), and C_c^infty(-L,L), are a COMMON CORE for A and D.
  That is the correct scope.  Two things are NOT true on the fixed window:

  (i) e^{tD} is NOT a unitary group on L^2[-L,L]: translation moves support out.
      a zero-extended window function f, supp f = [-L,L], shifted by t:
      t=0.10   supp(f(.-t)) = [-0.70,+0.90]  overlap with [-L,L] = 1.50  mass retained after re-restriction <= 0.938
      t=0.40   supp(f(.-t)) = [-0.40,+1.20]  overlap with [-L,L] = 1.20  mass retained after re-restriction <= 0.750
      t=0.80   supp(f(.-t)) = [+0.00,+1.60]  overlap with [-L,L] = 0.80  mass retained after re-restriction <= 0.500
      t=1.60   supp(f(.-t)) = [+0.80,+2.40]  overlap with [-L,L] = 0.00  mass retained after re-restriction <= 0.000
      -> the zero-extended window functions are NOT a translation-invariant space,
         so there is no translation group ON that space to be generated.

  (ii) D with NO boundary condition is not skew-adjoint on L^2[-L,L].
       integration by parts leaves the boundary term [f g]_{-L}^{L}:
       both vanish at +-L   <Df,g> = -1.2228755e-13 <f,Dg> = -3.6577971e-13 sum = -4.8806726e-13 boundary = 0.0000000e+00
       NEITHER vanishes     <Df,g> = 3.2000000e+00 <f,Dg> = -1.6000000e+00 sum = 1.6000000e+00 boundary = 1.6000000e+00
       skew-adjointness needs <Df,g> = -<f,Dg>, i.e. sum = 0, which holds only
       when the boundary term vanishes.  (cf. Bonneau-Faraut-Valent on momentum-
       operator domains; NOT CHECKED here, cited as the reviewer supplied it.)

  CONCLUSION: [A,D] = -I is a relationship on a common core, NOT an identification,
  and NOT a statement about two globally defined generators on one fixed-window
  space.  A is bounded self-adjoint on L^2[-L,L] (||A|| = L); D is the generator of
  translations on L^2(R), where the Sonin/scaling action actually lives.
