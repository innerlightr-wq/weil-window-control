9.  FAKE-GENERATOR CONTROL (control 2)
==============================================================================
  Any even analytic function of a parameter is a power series in that parameter
  squared.  So an even Taylor series is NOT evidence for a scaling generator.
   witness g(x) = cos(x) + exp(-x^2):  g(x) = 2.0000 -2.0000 x^2 +0.5417 x^4 + ...
     x=0.10  g = 1.9850540e+00 even series = 1.9800542e+00 dev = 4.9998324e-03
     x=0.30  g = 1.8692677e+00 even series = 1.8243875e+00 dev = 4.4880174e-02
     x=0.50  g = 1.6563833e+00 even series = 1.5338542e+00 dev = 1.2252918e-01
   g is even and analytic, so g(x) = sum a_k x^{2k}, and one can ALWAYS write
   g(x) 'formally' as 2I + x^2 A^2 + ... by DEFINING A^2 := a_1 I, A^4 := 12 a_2 I, ...
   but those definitions need not come from one operator: consistency requires
   a_2 = a_1^2/12 for a single A with A^4 = (A^2)^2.  Check the witness:
     a_1 = -2.000000  a_1^2/12 = 0.333333  a_2 = 0.541667  consistent? False
   -> NOT consistent, so no single generator reproduces it.  Taylor matching alone
      proves nothing.  CONTRAST: the real quartet case passes this test exactly,
      because F(gamma+i delta) = Fhat(e^{-delta A} f)(gamma) holds at ALL orders
      (checks.py section 3) -- an identity, not a coefficient match.

10. COMPOSITION CONTROL (control 3)
==============================================================================
  A system where eta = arctanh(2 delta) is valid algebra but has NO native
  additive dynamics: a single Bernoulli trial with p = 1/2 + delta.
  There is no binary operation on two independent trials that composes their
  p's by Moebius addition; the natural operations are:
   p1=0.60 p2=0.70 | product (AND) p1 p2 = 0.4200 -> delta = -0.0800
                  | mixture (1/2,1/2)  = 0.6500 -> delta = +0.1500  (= (d1+d2)/2)
                  | Moebius d1(+)d2    = +0.2778  <- matches NEITHER
   p1=0.75 p2=0.55 | product (AND) p1 p2 = 0.4125 -> delta = -0.0875
                  | mixture (1/2,1/2)  = 0.6500 -> delta = +0.1500  (= (d1+d2)/2)
                  | Moebius d1(+)d2    = +0.2857  <- matches NEITHER
  So the hyperbolic coordinate is exact as algebra and empty as dynamics here.
  This is the manuscript's own 'exact translation, no shared dynamics' case.
