[F] FEASIBILITY GATE ON A COMPLETE DIFFERENTIABLE FAMILY
    Convergence.  On the real-z axis the repository bases give Psi_ij(z) =
    O(|z|^{-4}) (both bases vanish at +-L, so G = O(|Im w|^{-2})), and the zero
    density of H_tau is O(log|z|), so sum_k |Psi(z_k)| converges ABSOLUTELY for
    real zeros, and also for zeros confined to a bounded strip, since Psi grows
    only like e^{L|Im z|} there while still decaying like |Re z|^{-4}.  JUSTIFIED.
    Reality and orbit pairing.  Zeros come in the orbit {z, -z, conj z, -conj z}
    and Psi is even with Psi(conj z) = conj Psi(z), so each complete orbit
    contributes a real symmetric matrix.  JUSTIFIED (same convention as the
    parent extension, whose unit tests cover it).
    tau = 0 agreement.  JUSTIFIED by reuse of the parent Phase C gate (T2-N).
    Differentiability in tau.  NOT JUSTIFIED here.  Simple zeros move
    analytically, and a FIXED zero-free contour gives an analytic finite-contour
    family; but differentiating the COMPLETE sum term by term needs a uniform
    bound on sum_k |Psi'(z_k) z_k'| with z_k' = H''/H'(z_k), which is not
    controlled near near-collisions, and a fixed contour can be crossed by a
    zero as tau varies.

    => Only a FINITE-CONTOUR differentiable family is justified.  The missing
       lemma is a uniform-in-tau tail bound for sum_{|z_k| > R} |Psi'(z_k) z_k'|
       on a parameter interval, together with a zero-crossing-free contour on
       that interval.  Per the brief, the numerical tau-sweep branch is NOT run.

[K] ARITHMETIC CONTENT OF THE EVOLUTION AT tau = 0
    Away from zeros, with l = d_z log H,
      d_z^2 H / H = d_z l + l^2,  so  d_tau l = -d_z(d_z l + l^2)
                                            = -d_z^2 l - 2 l d_z l.
    (Verified symbolically above; it is an identity, not an assumption.)
    At tau = 0, l_0(z) = (i/2) (xi'/xi)(1/2 + iz/2) and
      xi'/xi(s) = 1/s + 1/(s-1) - (1/2)log pi + (1/2)psi(s/2) + zeta'/zeta(s),
      -zeta'/zeta(s) = sum_n Lambda(n) n^{-s}      (Re s > 1).
    So the QUADRATIC term in the evolution carries
      l^2  ->  (sum_n Lambda(n) n^{-s})^2 = sum_n (Lambda * Lambda)(n) n^{-s},
    a divisor convolution supported on products of TWO prime powers.  Its
    coefficients are FORCED by the source equation, which is genuinely different
    from deleting mixed terms by hand (parent Phase H).

    But: (a) the Dirichlet series for l^2 converges absolutely only for
    Re s > 1, i.e. |Im z| > 1, which is OUTSIDE the strip where the zeros and
    the detector live, and continuing it termwise into the strip is exactly the
    step the brief forbids; (b) (Lambda*Lambda)(n) >= 0, but it enters d_tau Q
    through d_z Psi, which is sign-indefinite on the contour, so the convolution
    supplies no sign; (c) for tau != 0 the kernel e^{tau x^2}Phi(x) is not the
    kernel of any Dirichlet series, so H_tau has NO Euler product, NO
    gamma-factor decomposition and NO prime-side explicit formula.  The
    arithmetic exists only at the single point tau = 0.

    So the honest answer to the brief's question is the second alternative: the
    source equation generates another exact but sign-indefinite expression, in a
    half-plane disjoint from where it would have to be used.

[G] ADVERSARIAL CONTROL 1: the generic heat-flow family F_tau(z) = z^2 + a^2 - 2tau
    d_tau F = -2 and d_z^2 F = 2, so d_tau F = -d_z^2 F: the SAME equation.
    Zeros z = +- sqrt(2 tau - a^2): purely imaginary for tau < a^2/2, real for
    tau >= a^2/2.  Its initial strip half-width is Delta = a, and it becomes
    real exactly at tau = Delta^2/2 -- it SATURATES de Bruijn Theorem 7.
      a = 1                      transition at tau = a^2/2 = 0.5
      a = 1.790272316470219442   transition at tau = a^2/2 = 1.60253748355982278
    Consequence: the transition from non-real to real zeros, and hence the
    transition of the detector from indefinite to positive semidefinite, is
    produced by the heat equation and the initial strip width ALONE, with no
    arithmetic input whatsoever.  Any argument that derives a zero restriction
    from the source equation plus a strip bound must therefore also apply to
    F_tau, and so cannot be arithmetic in content.
    Hypothesis check.  F_tau is NOT the Fourier transform of an integrable,
    rapidly decaying kernel: such a transform is BOUNDED on the real axis, and a
    degree-2 polynomial is not.  So F_tau is a POLYNOMIAL HEAT-FLOW CONTROL that
    reproduces the strip-shrinking RATE; it is not an example satisfying every
    hypothesis of Theorem 7, and it is not a counterexample to it.  The relevant

[L] POSITIVE KERNEL => PSD CORRELATION MATRIX, WHICH IS A DIFFERENT FORM
    For any nonnegative integrable Phi with Fourier transform Phi^(y),
      sum_{j,k} c_j conj(c_k) Phi^(y_j - y_k)
          = int Phi(x) |sum_j c_j e^{i y_j x}|^2 dx  >=  0,
    so a positive kernel generates a POSITIVE SEMIDEFINITE matrix of Fourier
    correlations.  For the DH kernel, Phi_F^(y) = Lambda_F(1/2 + i y/2), so the
    matrix M_jk = Lambda_F(1/2 + i(y_j - y_k)/2) must be PSD.  Checked:
      y = ['0.0', '1.0', '2.5', '4.0', '7.0']
      eigenvalues: 2.411328132e-5, 0.002983011492, 0.1416783233, 1.363815621, 5.657459774
      least eigenvalue = 2.411328132e-5  ->  PSD

    AND YET Q^DH_0 has a certified NEGATIVE witness.  There is no contradiction:
    these are different quadratic forms built from different aspects of the same
    function -- one from the kernel's correlations, one from the zeros.  The
    lesson for a layered programme is exact:
      POSITIVITY IN THE CORRELATION GEOMETRY DOES NOT TRANSFER TO POSITIVITY IN
      THE ZERO GEOMETRY.
    Finding "something positive" is not the missing bridge; proving that a
    particular positive structure controls the particular spectral form that
    matters is.

    CONSEQUENCE.  Suppose there were an inequality of the sought form
        eta'(theta) <= a(theta) (1 - eta(theta)),
    oriented so that eta <= 1 at large tau propagates DOWN to tau = 0, with a
    controlled by hypotheses that the DH kernel satisfies -- i.e. by (10), (11),
    kernel positivity, a strip bound, and the heat equation.  Applied to DH it
    would give Q^DH_0 >= 0 on the stated space, contradicting (v)-(vi).
    Therefore NO UNIVERSALLY APPLICABLE backward-preservation argument resting
    only on those shared hypotheses can work.  The precise conclusion is not
    "the inequality cannot exist" but: somewhere along the required path from
    tau = tau_DH down to tau = 0, one of its ingredients must fail -- the
    inequality itself, the control on a(theta), the differentiability, or the
    standing assumption B_tau > 0.  The channel representation needs B_tau > 0
    at every tau, and tracking individual zeros can meet collisions; neither can
    be carried along the whole path for free.

    This does not refute a backward inequality that uses a hypothesis DH fails.
    The only candidate the parent work supplies is an Euler product: DH has none,
    and zeta does.  So any surviving route must use the Euler product in an
    essential way -- and the parent Phase H already showed that deleting the
    non-Euler part of the arithmetic side is not a usable way to do that
    (lambda_min of the truncation is negative at 17 of 18 configurations,
    including where the true form is positive).
